What exactly is $EGOR?

$EGOR is a community meme-token project on TON, presented as a tribute to Egor Zhgun’s creative work. It is a speculative token, not an ownership stake in his art or a claim on his intellectual property.

Is this Egor’s official token?

No official endorsement or partnership has been established for this website. This is a community tribute, not Egor’s official website. The project character is shown from supplied reference artwork; authorship is not independently established here.

What do the creator reward records prove?

The dated records below contain comments referring to creator rewards for $EGOR from Topblast. A transfer comment alone does not prove a fixed trading fee, the identity of the recipient, an ongoing reward arrangement, or artist endorsement. Amounts and totals are withheld while the source discrepancy and display units remain unresolved.

What is the token supply?

The supplied metadata lists a maximum supply of 1,000,000,000 EGOR and “mintable: false.” Verify these details against the full deployed contract before making a transaction.

How do I swap Gram for $EGOR?

Use the Swap on DeDust link to open the project-supplied Gram-to-EGOR pair in a new tab. The link retains DeDust’s supplied TON asset identifier; confirm the live interface before proceeding. Match the receiving token to the full contract address displayed on this site and verify it independently. Check liquidity, minimum received, price impact, and fees before signing in your wallet. This website does not execute transactions. See DeDust’s swap guide for the interface steps.

What is Gram, and what is TON?

TON (The Open Network) is the blockchain. Gram (GRAM) is the native-coin name shown in the official TON website snapshot reviewed for this release (November 2, 2026). $EGOR is a separate community token on that network. The supplied DeDust URL retains the technical asset identifier TON; always check the live paying asset and network before signing.

What should I know before buying?

Meme tokens are highly speculative. Prices can be volatile, liquidity can disappear, and you can lose your entire purchase. There are no guaranteed returns. Never share your recovery phrase, and never trade using an unverified token address.

What does this website store or measure?

Your doodles and signal-card messages stay in page memory and are never uploaded; save a PNG before leaving or reloading. Your motion preference is stored in this browser, and a session flag skips repeat introductions. On a configured Vercel deployment, optional Web Analytics and Speed Insights measure visits and page performance. This integration respects browser Do Not Track and Global Privacy Control signals and removes query strings and fragments from monitored page URLs. It sends no custom copy or swap events and never accesses your wallet. Hosting providers may also process request logs. See Vercel’s analytics privacy information.
